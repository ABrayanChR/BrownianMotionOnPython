# BrownianMotionOnPython
Simulación en Python del movimiento browniano en 3D mediante la ecuación de Langevin (Euler-Maruyama): genera trayectorias para distintos coeficientes de difusión, las guarda en .npz, las anima con fondo transparente y contrasta los resultados con la teoría (equipartición y Maxwell-Boltzmann).
